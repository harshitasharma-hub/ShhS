# docs

Reference files from outside the repo, and the pictures of the main README.

| File | What it is |
| --- | --- |
| `challenge-04-concept-note.pdf` | The concept note for Challenge 04 of the Hack-Nation x World Bank Small AI for Development hackathon. It lists the rules of the challenge and how entries are scored. |
| `klein-2024-synthetic-data-at-scale.pdf` | Klein et al. (2024), "Synthetic data at scale: a development model to efficiently leverage machine learning in agriculture", Frontiers in Plant Science 15:1360113 (CC BY). We followed its lesson: judge synthetic data by the score on real photos. |
| `readme/` | The banner (`hero.gif`, and `hero-still.png` for readers who turn motion off) and the results chart (`results.png`) at the top of the main README. Made by `scripts/analyze/make_readme_art.py`, so do not edit them by hand. |
| `accessibility-study.md` | A desk study of how to make the hosted demo usable by farmers who find devices hard, and what we changed because of it. The pictures are in `accessibility-study/`. |
